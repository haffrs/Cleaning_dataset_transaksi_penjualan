# Cleaning_dataset_transaksi_penjualan
Proyek ini berfokus pada proses pembersihan data menggunakan Microsoft Excel agar dataset siap digunakan untuk analisis, visualisasi, maupun reporting.  Proses data cleaning meliputi: - Menghapus data duplikat - Menangani missing values - Standardisasi format data - Perbaikan typo - Formatting tanggal &amp; angka - Filtering dan validasi data
